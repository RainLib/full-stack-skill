# 全栈技术选型模板

## 前端

| 项     | 选型示例        | 说明     |
|--------|-----------------|----------|
| 语言   | TypeScript/JavaScript | 选一     |
| 框架   | React / Vue / Next.js / ... | 与后端对接方式考虑 |
| 状态   | （如 Redux / Zustand / Pinia） | 按需     |
| 请求   | fetch / axios   | 与后端 API 约定一致 |

## 后端

| 项     | 选型示例        | 说明     |
|--------|-----------------|----------|
| 语言   | Java / Node / Go / Python / ... | 选一     |
| 框架   | Spring Boot / Express / FastAPI / ... | 与前端协议一致 |
| API    | REST / GraphQL  | 选一并约定规范 |

## 数据与存储

| 项     | 选型示例        | 说明     |
|--------|-----------------|----------|
| 数据库 | 关系型 / 文档型 / 内存 | 按需求选 |
| 缓存   | （如 Redis）    | 按需     |
