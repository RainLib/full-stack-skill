# 仅前端技术选型模板

## 前端

| 项     | 选型示例        | 说明     |
|--------|-----------------|----------|
| 语言   | TypeScript / JavaScript | 选一     |
| 框架   | React / Vue / Next.js / ... | 选一     |
| 状态   | （按需）        | 本地状态 / 全局状态 |
| 数据   | Mock / 本地存储 / 静态 JSON | 无后端时的数据来源 |

## 构建与运行

| 项     | 选型示例        |
|--------|-----------------|
| 构建   | Vite / Create React App / Nuxt / ... |
| 运行   | 浏览器、Node（若 SSR） |

## 说明

- 若后续会接真实后端，可在「接口约定」中预留 API 形状与协议（REST/GraphQL 等）。
