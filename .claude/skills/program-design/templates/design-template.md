## 4. API 设计（核心接口）

### POST /api/auth/login

- **请求体**：

```json
{
  "email": "string",
  "password": "string"
}
```

- **响应体**（200）：

```json
{
  "token": "string",
  "user": { "id": "number", "email": "string" }
}
```

- **错误**：400 参数无效 / 401 凭证错误

## 6. 错误处理策略

### 后端

| 错误码 | 含义 | HTTP 状态码 |
|--------|------|:-----------:|
| AUTH_001 | 未认证 | 401 |
| VALID_001 | 参数校验失败 | 400 |
| （更多...） | | |

### 前端

- 全局拦截：401 → 跳转登录；500 → 通用错误提示
- 局部处理：表单校验错误 → 字段级提示
