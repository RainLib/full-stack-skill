## 3. API 设计（核心接口）

### POST /api/auth/login

- **请求体**：

```json
{
  "email": "string",
  "password": "string"
}
```

- **响应体**（200）：

```json
{
  "token": "string",
  "user": { "id": "number", "email": "string" }
}
```

- **错误**：400 参数无效 / 401 凭证错误
