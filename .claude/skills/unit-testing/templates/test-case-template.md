# 单元测试用例文档

## 1. 测试策略

### 框架约定

| 层 | 测试框架 | Mock 工具 |
|----|----------|-----------|
| 后端 | JUnit / pytest / Jest / ... | Mockito / unittest.mock / ... |
| 前端 | Jest / Vitest / ... | React Testing Library / ... |

### 覆盖率目标

| 模块类型 | 行覆盖率目标 |
|----------|:------------:|
| 核心业务逻辑 | ≥80% |
| API 控制器 | ≥70% |
| 工具/配置 | ≥50% |

### Mock 策略

| 依赖 | Mock 方式 | 说明 |
|------|-----------|------|
| 数据库 | 内存数据库 / Repository mock | |
| 外部 API | HTTP mock / 固定响应 | |
| 文件系统 | 临时目录 / mock | |
