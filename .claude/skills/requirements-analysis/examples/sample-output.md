# 需求文档

## 1. 项目概述

- **项目名称**：ProjectX
- **一句话描述**：面向中小企业的在线订单管理平台，支持多角色协作处理订单全流程
- **输入来源**：用户口述 + 简要功能列表

## 2. 用户与角色

| 角色 | 权限范围 | 说明 |
|------|----------|------|
| 管理员 | 全局配置、用户管理、数据导出 | 系统最高权限 |
| 操作员 | 创建/编辑/跟踪订单 | 日常业务操作 |
| 查看者 | 只读查看订单与统计 | 主管或外部合作方 |

## 4. 用户故事（核心功能）

### US-01：创建订单

- **As a** 操作员
- **I want** 填写客户和商品信息后快速创建一笔订单
- **So that** 业务流程能及时启动，客户不必等待
- **验收标准**：
  1. Given 操作员已登录，When 点击"新建订单"并填写必填项后提交，Then 订单创建成功并跳转到订单详情页
  2. Given 必填项未填写完整，When 提交，Then 显示字段级错误提示且不提交

### US-02：订单状态流转

- **As a** 操作员
- **I want** 将订单从"待确认"推进到"处理中"或"已取消"
- **So that** 订单进度可追踪，上下游可获知当前状态
- **验收标准**：
  1. Given 订单处于"待确认"，When 操作员点击"确认"，Then 状态变为"处理中"并记录操作日志
  2. Given 订单处于"已完成"，When 尝试操作，Then 按钮置灰且不可点击

## 5. 业务流程

### 流程一：订单全流程

```
创建订单 → 待确认 → 确认 → 处理中 → 标记完成 → 已完成
                 ↓                    ↓
              取消订单              取消订单
                 ↓                    ↓
              已取消                已取消
```
